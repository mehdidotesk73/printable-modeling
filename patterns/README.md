# Patterns

Consolidated design knowledge, extracted from cases during "consolidate" sessions.

Each claim looks like:

> **Claim** — status: `observed` | `emerging` | `rule` — cases: [001](../cases/001-.../notes.md)
> Conditions/caveats.

- `observed`: seen in one case
- `emerging`: seen in two or more cases
- `rule`: the user confirmed it

Contradicting cases are logged under **Open questions**, not averaged.
